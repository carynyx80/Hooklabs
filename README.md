# Hook Labs — Your Treasury. On Autopilot.

Landing page for Hook Labs: autonomous AI agents for on-chain token treasuries on BNB Chain. The full application is in development.

## Run locally

```powershell
npm install
npm run dev
# open http://localhost:3003
```

## Build

```powershell
npm run build
```

Static landing page — no wallet, no backend, no environment variables required.
